- 🖼️ **PNG transparente 1200×1200** — Listo para subir a cualquier app de mensajería
- ⭕ **3 formas de sticker** — Libre (contorno orgánico), círculo y cuadrado redondeado
- 🎨 **Borde personalizable** — Grosor de 0 a 30 px y color libre
- 🌫️ **Sombra suave opcional** — Efecto de profundidad profesional
- 🔍 **Escala ajustable** — Del 70% al 130% sobre el lienzo
- 📂 **Drag & drop** — Arrastra la imagen o selecciónala (PNG, JPG, WEBP hasta 10 MB)
- ⚡ **Sin instalación** — Un solo archivo HTML, funciona abriéndolo directamente

## ✨ Features

- 🤖 **AI-powered automatic cutout** — Person segmentation with TensorFlow.js + BodyPix
- 🔒 **Total privacy** — The model downloads once (~8 MB) and all processing is local
- 🖼️ **1200×1200 transparent PNG** — Ready to upload to any messaging app
- ⭕ **3 sticker shapes** — Free (organic contour), circle, and rounded square
- 🎨 **Customizable border** — Thickness from 0 to 30 px with any color
- 🌫️ **Optional soft shadow** — Professional depth effect
- 🔍 **Adjustable scale** — 70% to 130% on the canvas
- 📂 **Drag & drop** — Drag the image or select it (PNG, JPG, WEBP up to 10 MB)
- ⚡ **No installation** — A single HTML file, works by opening it directly
